About the Project

Pioneering Genomic-Driven
Maize Hybrid Breeding

Combining SNP genotyping, multi-output machine learning, and agronomic environmental features to accelerate hybrid breeding pipelines.

Project Overview

CrossWise is an agricultural AI platform designed to help maize breeders predict the phenotypic performance of hybrid cultivars prior to expensive multi-environment field trials. By analyzing 300+ SNP markers across inbred parent lines alongside environmental parameters (rainfall, temperature, humidity), our model simulates all pairwise crosses and predicts Yield Potential, Drought Tolerance, Disease Resistance, Grain Quality, and Maturity Period.

Machine Learning Model

The core engine utilizes an ensemble of high-capacity Random Forest Regressors and calibrated multi-class classifiers trained on validated agricultural genomic datasets. CrossWise pre-computes genomic compatibility, applies variance filtering and biological feature engineering (heterozygosity, minor allele burden), and provides global and local SHAP explainability.
